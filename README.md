Typed TypeScript client for the [Seq](https://datalust.co/seq) HTTP API written for [llm-chat-seq](https://github.com/johanneslatzel/llm-chat-seq).

> **Disclaimer**: This package was written entirely by AI. Use at your own risk.

## Features

- events, signals, data queries, saved queries
- zero runtime dependencies

## Prerequisites

- Node.js >= 20.9

## Installation

```bash
npm install @johannes.latzel/seq-client
```
